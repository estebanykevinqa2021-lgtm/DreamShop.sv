# Dream Shop 🌸

Landing page de **Dream Shop** — *Arte que no se marchita*.
Ramos artesanales de cinta satinada, crochet, chocolates y Hot Wheels.

## Estructura

```
index.html          # página principal
css/styles.css      # estilos
assets/img/         # logo y fotos del catálogo
```

## Ver en local

Abre `index.html` en el navegador (doble clic).

## Publicar con GitHub Pages

1. Sube todo el contenido de esta carpeta a un repositorio (el `index.html` debe quedar en la raíz).
2. En GitHub: **Settings → Pages**.
3. En *Build and deployment*, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En uno o dos minutos la página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
